ADR 0001 — Stockage des données

ProposéType détecté : ADR (titres Contexte, Décision, Conséquences)
AR

Contexte

Troc sert un seul immeuble, de 40 à 200 logements. Les voisins consultent le catalogue depuis leur téléphone, souvent dans la cage d'escalier ou à la cave. Les données doivent rester disponibles hors ligne.1

AR

Décision

Nous stockons toutes les données dans une base PostgreSQL hébergée2, interrogée par une API REST.

AR
