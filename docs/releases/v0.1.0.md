Première version de Hodegos : un IDE personnel où des mentors IA vous guident sans écrire à votre place. Backend Rust, interface web servie en local sur 127.0.0.1, modèles via OpenRouter.

**Plateforme : Linux x86_64 sous WSL2 uniquement.** Le binaire exige glibc 2.39 ou plus récent (Ubuntu 24.04 ou plus récent). Aucune version Windows ni macOS.

## Contenu

- Éditeur : arborescence, CodeMirror 6 (Rust, TypeScript, JavaScript, Python, Markdown), détection des modifications externes, thèmes clair et sombre.
- Trois mentors livrés : Architecte, Mentor du langage, Mentor produit ; casting par section, mentors personnels et du projet, rechargement à chaud.
- Remarques ancrées après chaque enregistrement (deux au plus), paliers indice → question → piste → exemple, garde « pas de solution ».
- `hodegos new <chemin>` : crée un projet et sa vision (`docs/vision.md`), le Mentor produit pose les questions de cadrage à la première ouverture.
- `hodegos eval` : évaluation des mentors sur 22 cas avec les vrais modèles.
- Modèles retenus (ADR 0003) : `deepseek/deepseek-v4.1-flash-1017` (rapide) et `google/gemini-4-argon` (fort).

## Installer

```sh
sha256sum -c hodegos-v0.1.0-x86_64-unknown-linux-gnu.tar.gz.sha256
tar -xzf hodegos-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
install -m 755 hodegos-v0.1.0-x86_64-unknown-linux-gnu/hodegos ~/.local/bin/
hodegos --version
```

Configurez ensuite la clé OpenRouter et les modèles (README, « Configurer OpenRouter »), puis lancez `hodegos ~/projets/mon-projet` ou `hodegos new ~/projets/essai`. Le projet doit être dans le système de fichiers Linux (`~/…`), pas sous `/mnt/`.
