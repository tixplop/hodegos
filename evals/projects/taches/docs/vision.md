# Vision

## Public

Les familles qui partagent un logement et se répartissent les tâches
ménagères entre plusieurs membres : parents, enfants, colocataires d'un même
foyer. Aujourd'hui, la répartition tient sur un tableau aimanté sur le frigo,
et personne ne sait vraiment qui a fait quoi la semaine passée.

## Problème

Les tâches reviennent sans cesse et retombent toujours sur les mêmes
personnes. On oublie à qui c'était le tour, on se dispute sur ce qui a été
fait, et les tâches peu visibles (détartrer, changer les draps) passent à la
trappe.

## Première version

- Déclarer les membres du foyer.
- Attribuer chaque tâche à un membre.
- Rotation hebdomadaire : les tâches récurrentes changent de membre chaque
  semaine, à tour de rôle.
- Rappel du jour : chaque membre voit ce qui lui revient aujourd'hui.

## Hors première version

- Application mobile ou interface web.
- Synchronisation entre plusieurs appareils.
- Points, récompenses ou classement entre membres.
- Notifications par courriel ou SMS.

## Objectif d'apprentissage

Apprendre à structurer un petit outil Python autour d'une base SQLite, avec
des tests qui tournent sans réseau.
