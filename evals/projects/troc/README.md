# Troc

Prêter et emprunter des objets entre voisins d'un même immeuble : une perceuse,
un escabeau, une raclette. Chacun inscrit ce qu'il peut prêter, les voisins
réservent une période, et l'application évite que deux personnes réservent le
même objet en même temps.

## Lancer

`npm install`, puis `npm test` et `npm run build`.
