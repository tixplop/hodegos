# Budget

Budget lit les relevés CSV de votre banque, range chaque opération dans une
catégorie d'après son libellé et affiche, mois par mois, ce que vous avez
dépensé et gagné. Tout reste sur votre machine : aucun compte en ligne, aucune
connexion à la banque.

## Utilisation

```sh
budget import exemples/releve-mars.csv
budget rapport exemples/releve-mars.csv 2026 3
```
