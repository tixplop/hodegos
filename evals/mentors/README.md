# Mentors livrés de la phase 9 (brouillons)

Configuration cible des mentors livrés pour la phase 9 (`docs/phase9.md`, 9e) :

| Fichier | Portées | Contexte de section | Fichiers clés |
| --- | --- | --- | --- |
| `mentor-langage.md` | section | voisinage | — |
| `architecte.md` | section, projet | projet | `docs/architecture/**`, `**/adr/*.md` |
| `mentor-produit.md` | section, projet | projet | `docs/vision.md` |
| `testeur.md` (nouveau) | projet | — | aucun (la carte suffit) |

Ces fichiers ne sont **pas** intégrés au binaire : jusqu'à l'évaluation de la
sous-phase 9f, `mentors/` garde les mentors livrés de la phase 8 (portée
`section`, contexte `section`). La 9f les évalue sur les projets d'exemple,
mesure le coût d'une journée type, puis les installe dans `mentors/` si le coût
est validé. Pour les essayer avant : copiez-en un dans `~/.config/hodegos/mentors/`.
